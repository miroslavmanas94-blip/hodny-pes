# Hodný pes: Psí dobrodružství

Česká 3D webová adventura pro výcvik psů a Dog Puller. Projekt je ve vývoji; stav jednotlivých funkcí je veden transparentně.

## Stav

- Základ projektu: připravuje se
- Cloudový postup: vyžaduje konfiguraci Supabase
- Online multiplayer: není zatím aktivní

Viz `docs/setup.md` pro lokální spuštění a konfiguraci.
